## 🌌 What is ZChat?

> **A visceral communication experience.**

**ZChat** isn’t just another chat app — it’s a *night‑first*, performance‑obsessed platform crafted
with Flutter.
Every interaction is tuned for speed. Every pixel respects the dark.

If messaging apps were sports cars, **ZChat** would be carbon fiber.

---

## ✨ Features that Hit Different

### 🌑 True Dark Mode (OLED-first)

* Designed from *absolute black* `#0A0A0D`
* Battery‑friendly
* Zero eye‑burn at 3 AM

### 💨 Full Swipe Navigation

* No tabs. No buttons.
* **Swipe between Chats, ZPosts, and Calls**
* Custom `FullSwipeController` with:

    * Rubber‑band physics
    * Velocity‑based snapping
    * Gesture priority handling

### 🤖 Zane

> *A friend? A bot? The singularity?*

* Conversational AI companion
* Fast, reactive, mysterious
* *"Father, are you proud?"*

### 📱 ZPosts

* A dedicated feed for content that matters
* Built for clarity, not noise

### 📞 Crystal‑Clear Calls

* Integrated calling experience
* Designed to feel native, not bolted on

### 🎨 Design System

* **Inter & Inter Display** typography
* Custom spacing scale
* Motion‑first UI philosophy

## 🧠 Architecture Philosophy

```text
View  →  Widget  →  Data
        ↑
   AppNotifiers
```

* **Modular & predictable**
* No over‑engineered state managers
* Powered by `ValueNotifier` & `AppNotifiers`
* Easy to debug. Hard to break.
